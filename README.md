# ✻ YOGA

> Landing Page para estúdio de yoga com design minimalista, seções parallax e navegação suave.

🌐 **Website:** https://www.pablogdev.com.br  
🚀 **Demo:** https://pablog-7.github.io/yoga-harmonia/

---

## 🎯 Sobre o Projeto

A **YOGA** é um UI Concept de uma landing page para um estúdio de yoga desenvolvida para compor meu portfólio de desenvolvimento front-end. O projeto apresenta uma experiência visual serena com seções parallax, design minimalista e navegação suave entre as seções, criando uma atmosfera de harmonia e bem-estar.

Desenvolvido com HTML, CSS e JavaScript puro, este conceito demonstra a criação de landing pages elegantes e funcionais para o setor de bem-estar e saúde.

## ⚡ Funcionalidades

### 🏠 Hero Sections (Parallax)

- 4 seções com efeito parallax
- Fundos com imagens de alta qualidade
- Overlay suave para legibilidade
- Títulos com fonte Playfair Display
- Descrições inspiracionais

### 📖 Sobre Nós

- Texto institucional com chamada para ação
- Imagem lateral com pessoa meditando
- Layout alternado entre seções
- Botão "Leia mais"

### 🧘 Filosofia

- Seção com layout reverso
- Texto sobre a filosofia do estúdio
- Imagem com paisagem zen
- Botão para navegar até as aulas

### 🧘‍♀️ Aulas

- 3 cards com modalidades
- Vinyasa Flow, Hatha Yoga e Meditação Guiada
- Descrição de cada modalidade
- Horários das turmas
- Efeito hover com elevação

### 📞 Contato

- Informações de contato (telefone, email, endereço)
- Formulário de mensagem integrado
- Campos: Nome, Email, Mensagem
- Botão de envio estilizado

### 📅 Reservas Online

- Box de reserva com destaque
- Informações das turmas disponíveis
- Campo para nome completo
- Botão para reservar vaga

## 🎨 Destaques do Design

- **Header Transparente** - Começa transparente e fica com blur ao rolar
- **Tipografia Elegante** - Playfair Display (serif) + Lato (sans-serif)
- **Efeito Parallax** - Imagens com scroll dinâmico
- **Minimalismo** - Design limpo e focado na experiência
- **Scrollbar Customizada** - Estilização com tom escuro
- **Navegação Ativa** - Links destacam conforme a seção visível
- **Cards com Hover** - Elevação suave ao passar o mouse
- **Layout Alternado** - Conteúdo e imagem se alternam entre seções
- **Paleta Neutra** - Tons de cinza, branco e escuro

---

## 📱 Responsividade

- **Mobile** - Otimizado para smartphones (até 480px)
- **Tablet** - Layout adaptado para telas médias
- **Desktop** - Experiência completa em telas maiores

## 💼 Sobre este Case
